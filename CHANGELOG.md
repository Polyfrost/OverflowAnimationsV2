## 5.1.0
- Reorganized the config into Position, Interaction, Item Visual and HUD tabs, with less common options moved to an Advanced section.
- Rewrote option names and descriptions to be shorter and easier to understand.
- Several toggles are now choices between versions, like 1.7 or 1.8+ item positions, block hitting and heart flashing.
- 1.8.9 now uses its own config file, copied from the shared one on first launch.
- "Red Held Item When Hit" can now be set to first person, third person, both or off.
- Added an option to scale animations with item scaling.
- Added an option to scale empty hand with item scaling.
- Removed the 2D Mob Head Items option.
